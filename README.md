
BTC Crowdfund Smart Contract
This repository contains a Clarity smart contract for decentralized crowdfunding on the Stacks blockchain. The contract allows users to create campaigns, contribute STX tokens, finalize campaigns, withdraw funds, and claim refunds if a campaign fails.

Features
Create Campaigns: Anyone can start a new crowdfunding campaign with a funding goal and deadline.
Contribute STX: Supporters can contribute STX tokens to active campaigns.
Finalize Campaigns: After the deadline, campaigns are marked as successful or failed based on whether the funding goal was met.
Withdraw Funds: Campaign creators can withdraw funds if their campaign is successful.
Claim Refunds: Contributors can claim refunds if a campaign fails.
Usage
Deploy the contract to the Stacks blockchain and interact using Clarity functions:

create-campaign
contribute
finalize-campaign
withdraw-funds
